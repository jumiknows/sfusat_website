# Security

The SFU SAT website is public. Keep credentials and private member information out of the repository.

## Do not commit

- passwords or recovery codes
- DNS, hosting, SMTP, or API credentials
- private member contact information
- unapproved headshots or private documents
- contact-form submissions

Use fictional data in screenshots and issues when a reproduction needs form content.

## Reporting

If you find an exposed credential or a vulnerability that could reveal private information, report it privately to the repository owner rather than posting the sensitive value in a public issue.

Ordinary website bugs can use the normal GitHub issue templates.
